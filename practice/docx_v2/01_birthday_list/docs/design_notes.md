# Design Notes

Answer these before or after implementation:

1. Which invariant must always relate `names_` and `birthdays_`?
2. What happens if an operation updates one vector but not the other?
3. Which date calculations belong in `Day` rather than `BirthdayList`?
4. What public behavior would change if the parallel vectors were replaced by
   a vector of `Person` objects?

These questions are part of the practice task; there is intentionally no model
answer in this folder.
