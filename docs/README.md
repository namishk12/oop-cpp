C++ examples. Open them in the Mermaid Live Editor or a Mermaid-enabled editor.

For slide-based lab midsem practice, see
[`practice/midsem/`](../practice/midsem/README.md). Those projects are
intentionally red at the start so that they can be solved with TDD.
